รวมชื่อไทย–อังกฤษ 58 คู่ และชื่อย่อ 8 รายการ ผ่านการวิเคราะห์ถอดเสียงและ fuzzy matching

🎓 ตารางคุณสมบัติอาจารย์ประจำหลักสูตร

#ชื่ออาจารย์ รวมนานาชาติSCOPUSQ1Q2TCI1 ผ่านเกณฑ์?มีผลงานนานาชาติ?
🔗 ระบบจับคู่ชื่อไทย–อังกฤษ ใช้ Thai romanization (ROYIN) + fuzzy string matching เพื่อระบุชื่อเดียวกัน ระบบจะใช้ชื่อภาษาไทยเป็น canonical และรวมผลงานทุกชื่อเข้าด้วยกัน รวมทั้งแก้ไขการสะกดซ้ำในชื่อไทย (เช่น "สังเฉย" → "สังข์เฉย") หากพบข้อผิดพลาดสามารถแจ้งได้
